# Backup evidence
Private header: scope/dates/format/media/cap, export job/status, exporter version,
UTC observation, storage/retention and exclusions. File: relative path, bytes,
SHA256, media role and readability. Message inventory: count, references,
missing/skipped reasons, topic/album/reply expectations and authorized comparisons.

Path containment before reads; no traversal/links or credentials. Bounded parsing,
explicit UTF-8. Manifest contains personal metadata: keep private. Digests prove
integrity since observation, not server completeness/authenticity.

Running with24files is partial. Done with selected media missing fails integrity;
size-cap exclusion is a declared gap. Matching hashes/readable samples verifies
retained data, not live import. Reposted new ID/date is content restoration, not
historical identity. Missing source-device secret history cannot be recovered here.

Sources: https://core.telegram.org/api/takeout,
https://desktop.telegram.org/changelog, https://core.telegram.org/api/end-to-end.
Actual export_status/secret_chat_status schemas define available capabilities.
